# 황해담 활어 발주 계산기 — 링크 만들기(배포) 안내

`index.html` 파일 하나가 계산기 전부입니다.
파일을 그냥 갖고만 있으면 **다른 사람에게 보낼 링크가 생기지 않습니다.**
아래 두 방법 중 하나로 인터넷에 올려야 링크가 만들어집니다.

---

## 방법 1. GitHub Pages (무료 · 권장)

한 번만 설정하면 주소가 바뀌지 않아서 계속 쓸 수 있습니다.

### 1단계. GitHub 가입
1. 인터넷 주소창에 `github.com` 입력
2. 오른쪽 위 **Sign up** 클릭 → 이메일로 가입 (무료)

### 2단계. 저장소(리포지토리) 만들기
1. 로그인 후 오른쪽 위 **+** 버튼 클릭 → **New repository** 클릭
2. **Repository name** 칸에 `fish-calc` 입력 (영어 소문자면 아무거나 됩니다)
3. **Public** 이 선택되어 있는지 확인
4. 초록색 **Create repository** 버튼 클릭

### 3단계. 파일 올리기
1. 만들어진 화면에서 **uploading an existing file** 이라는 파란 글씨 클릭
2. 컴퓨터에서 `index.html` 파일을 찾아 화면으로 **끌어다 놓기**
3. 아래 초록색 **Commit changes** 버튼 클릭

### 4단계. Pages 켜기 (링크 생성)
1. 저장소 화면 위쪽 탭에서 **Settings** 클릭
2. 왼쪽 메뉴에서 **Pages** 클릭
3. **Branch** 아래 드롭다운에서 `None` → **`main`** 으로 바꾸고 **Save** 클릭
4. 1~2분 기다렸다가 새로고침하면 위쪽에 링크가 나타납니다:
   `https://내아이디.github.io/fish-calc/`
5. 이 링크를 열어서 계산기가 나오면 성공! 이 주소를 카톡으로 공유하면 됩니다.

### 나중에 파일을 수정했다면?
저장소 화면에서 **Add file → Upload files** 로 새 `index.html`을 다시 끌어다 놓고
**Commit changes** 를 누르면 1~2분 뒤 같은 링크에 반영됩니다.

---

## 방법 2. Netlify Drop (가장 빠름 · 회원가입 없이 시작 가능)

1. 인터넷 주소창에 `app.netlify.com/drop` 입력
2. `index.html` 이 들어 있는 **폴더째로** 화면 가운데에 끌어다 놓기
3. 몇 초 뒤 `https://이상한이름.netlify.app` 같은 링크가 생깁니다
4. 그 링크를 열어 계산기가 나오면 성공

> 주의: 회원가입 없이 올린 링크는 일정 기간 후 사라질 수 있습니다.
> 계속 쓰려면 무료 회원가입을 하고 올리세요.

---

## 공유는 이렇게 하세요

1. 배포된 링크를 열고, 배수·인원을 원하는 값으로 조절
2. 위쪽 **[공유 링크 복사]** 버튼 클릭 (내가 보던 숫자가 링크 안에 담깁니다)
3. 카톡에 붙여넣어 전송
4. 받은 사람이 열면 **내가 보던 것과 똑같은 숫자**가 보입니다
5. 상대가 수정 못 하게 하려면 **[보기 전용 링크]** 버튼을 대신 누르세요

### 잘 되는지 확인하는 법
1. 생새우 배수를 4.5 → 3으로 바꾸고 [공유 링크 복사]
2. 크롬 **시크릿 창**(Cmd+Shift+N)을 열어 붙여넣기
3. 생새우 배수가 **3**으로 보이면 성공입니다
